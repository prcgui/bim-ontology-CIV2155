# Ontologia

Esta pasta reúne a representação dos conceitos, propriedades e relações do exemplo BIM.

Começar com poucos conceitos, suficientes para responder às perguntas definidas no planejamento. Salvar aqui o arquivo da ontologia no formato adotado, como Turtle (`.ttl`) ou OWL (`.owl`).

Documentar o significado dos conceitos e sua correspondência com os dados utilizados.
