# Consultas

Esta pasta reúne as perguntas e as consultas utilizadas para explorar a ontologia.

Para cada consulta, registrar a pergunta em linguagem comum e o arquivo correspondente. Caso seja utilizado SPARQL, salvar as consultas com a extensão `.rq`.

As perguntas serão definidas a partir do exemplo e dos dados disponíveis. Guardar as respostas obtidas na pasta `resultados/`.
