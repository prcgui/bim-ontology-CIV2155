# Resultados

Esta pasta reúne as respostas das consultas e as evidências de verificação do exemplo.

Salvar tabelas, imagens ou outros arquivos que ajudem a demonstrar o que foi obtido. Identificar a consulta e os dados que produziram cada resultado.

Registrar também limitações e diferenças entre o resultado esperado e o observado. Os resultados serão adicionados após a execução das consultas.
